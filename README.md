# ICA Safety Review

A guided review of a patient-safety event that runs entirely in the browser.

It builds role swimlanes from a timeline, shows handoffs and the steps that waited on others, surfaces hidden assumptions and responsibilities that no role believed were theirs, and supports cause and effect analysis, causal statements, an action plan grouped by strength, and a run chart.

Live page: https://keheilan.github.io/safety_review/

## Privacy

For fictional or de-identified cases only. Nothing is sent or stored by the page. A review leaves the browser only when the user copies it out.

## Methods

The tool follows quality improvement methods described by the Institute for Healthcare Improvement (QI Essentials Toolkit: cause and effect diagram, flowchart, run chart) and the RCA² approach to root cause analysis. All wording is original. This project is not affiliated with or endorsed by IHI.

It does not decide root causes, rate anyone's performance, or determine fault.
